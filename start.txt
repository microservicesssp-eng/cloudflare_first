ТоматОпт — frontend-каркас лендинга оптовой компании (томатная продукция)
=========================================================================

НАЗНАЧЕНИЕ
Учебный/тренинговый каркас сайта-лендинга компании, которая оптом продаёт
томатную пасту, резаные томаты и томатные соусы. Только frontend, без backend.
Цветовая гамма: красный + зелёный, повсюду иконки томатов.

ТЕХНОЛОГИИ
- Vite 5 (сборщик и dev-сервер)
- React 18 (язык: JavaScript, файлы .jsx / .js, TypeScript НЕ используется)
- react-router-dom 6 (маршрутизация между страницами)
- Чистый CSS (src/index.css), без UI-библиотек
- Google Maps embed (iframe, без API-ключа)

ЗАПУСК
  npm install
  npm run dev       # разработка, http://localhost:5173
  npm run build     # production-сборка в папку dist
  npm run preview   # просмотр собранной версии

ФУНКЦИОНАЛ
1. Виджет чата. Внизу справа на ВСЕХ страницах всегда виден красный
   кнопка-виджет «Онлайн-чат с компанией» с иконкой томата. По клику
   открывается окно чата и вызывается connectChat() — активация связи с
   backend. Пока backend нет, адрес API.chat = "#" (см. src/config.js), запрос
   не отправляется, в консоль пишется "[stub]". Ответ компании — заглушка.
2. Меню: «О нас», «Наши предложения», «Наши сертификаты», «Контакты».
   Каждый пункт — отдельная страница (маршруты /about, /offers,
   /certificates, /contacts). Главная "/" перенаправляет на /about.
3. «О нас» — описание компании и цифры.
4. «Наши предложения» — текст с предложениями и форма из 4 полей (имя,
   компания, телефон/e-mail, продукция и объём). Отправка через sendOffer()
   на API.offer = "#" (заглушка).
5. «Наши сертификаты» — текст и два изображения .jpeg.
6. «Контакты» — адрес, телефоны, e-mail и небольшая карта Google. Адрес и
   координаты меняются в src/config.js (COMPANY.address, COMPANY.mapQuery).

ПОДКЛЮЧЕНИЕ BACKEND В БУДУЩЕМ
В src/config.js замените "#" на реальные URL, например "/api/chat" и
"/api/offer". Функция post() в src/api.js отправит JSON методом POST.
Для настоящего чата в реальном времени можно заменить connectChat() на
подключение WebSocket.
